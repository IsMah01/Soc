# Outputs

This directory stores generated AI SOC analysis reports.

In version 1, each report is generated from:

- Raw alert data
- Selected SOC playbook
- LLM reasoning

No Cortex, MISP, VirusTotal, or external enrichment is used in this version.

Example generated files:

- `81924152_ai_report.md`
- `100200300_ai_report.md`
